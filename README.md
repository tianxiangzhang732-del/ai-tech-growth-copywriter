# AI 科技口播写稿助手

[下载完整技能包（ZIP）](./ai-tech-growth-copywriter.zip)

这个技能帮助中文科技创作者把一份选题、参考资料或现成草稿讲清楚。它可以写完整口播，也可以只处理一个问题，例如选哪种开头、前五秒的承诺能否在正文兑现、哪一句最能打动观众，或谁会愿意把内容转给谁。

## 安装

1. 点击上方的 ZIP。在 GitHub 文件页点击 **Download raw file** 下载。
2. 解压后，将整个 `ai-tech-growth-copywriter` 文件夹复制到项目的 `.agents/skills/` 目录。确认 `SKILL.md` 在该技能文件夹的第一层。
3. 在 Codex 新开一个项目对话，输入 `$ai-tech-growth-copywriter`，再附上材料。包内的中文安装说明也列出了对当前用户所有项目生效的安装位置。

例如，可以问：“请只看这篇稿子的前两句。给我两个能在正文中兑现的开头，并说明每个开头需要哪些证据。”
